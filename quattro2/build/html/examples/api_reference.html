@category $native

@method stop()

iOS の場合は applicationDidEnterBackground 時に、Android の場合は Activity.onStop() 時に通知されます。

@category $native.app

@method app.exit()
アプリケーションを終了します。

@method app.device()
端末情報を取得します。
@return {Object} 端末情報オブジェクト
端末情報オブジェクトのプロパティ
  - model {String} 端末の機種
  - os {String} 端末の OS 情報（OS 名、バージョン）
  - id {String} 端末の固有 ID（UUIDv4 形式）
@note
端末の固有 ID は、アンインストール後の再インストールで、変化する場合があります。

@method app.version()
ネイティブ側で設定されたバージョン情報を取得します。
@return {Object} バージョン情報オブジェクト
バージョン情報オブジェクトのプロパティ
  - name {String} バージョン文字列
  - code {Number} ビルド番号
  - ctime {String} アプリケーションのインストール日時（ISO 8601 形式）
  - mtime {String} アプリケーションの更新日時（ISO 8601 形式）

@method app.locale()
システムのロケール情報を取得します。
@return {String} 現在のロケール情報（"en-US" や "ja-JP" 等）

@method app.storage([data])
ローカル環境にデータを永続的に保存します。また、保存したデータの取得を行います。
@param option data {String} 保存する文字列
@return {String} 最後に保存した文字列
@note
引数 data を指定した場合は、data の保存処理を行います。
引数 data がない場合は、最後に保存した data を戻り値として返します。
保存する文字数が 32K（0x8000）を超える場合は、app.storage2(key, [data]) を使用してください。

@method app.storage2(key, [data])
キーを指定して、ローカル環境にデータを永続的に保存します。また、保存したデータの取得を行います。
@param key {String} 保存するキー
@param option data {String} 保存する文字列
@return {String} 最後に保存した文字列
@note
引数 data を指定した場合は、指定したキーに data を保存します。
引数 data がない場合は、指定したキーに保存された data を戻り値として返します。
@atention 'pref' と先頭が '__' で始まる文字列は、予約語のためキーには使用できません。

@method app.clipboard([data])
ローカル環境にデータを一時的に保存します。また、保存したデータの取得を行います。
@param option data {String} 保存する文字列
@return {String} 最後に保存した文字列
@note
引数 data を指定した場合は、data の保存処理を行います。
引数 data がない場合は、最後に保存した data を戻り値として返します。

@method app.importfile([filter], [multiple])
iCloudDrive や GoogleDrive などの外部ストレージからファイルをインポートします。インポートされたファイルのパスは、app.event.command('import', file) で通知されます。
@param option filter {Object} フィルタオブジェクト
@param option multiple {Boolean} 複数選択可（true）／不可（false）
@note
フィルタオブジェクトのプロパティ（参考：audio_player.html）
  - uti {Array} UTI 文字列の配列（iOS用）
  - mime {Array} MIME 文字列の配列（Android用）
@atention iOS/Android のみ対応です。
インポートされたファイルのパスは 60 秒程度で無効になります。

@method app.exportfile(file)
iCloudDrive や GoogleDrive などの外部ストレージへ、ファイルをエクスポートします。
@param file {String} エクスポートするファイルのパス
@atention iOS/Android のみ対応です。
@note
file をパスの配列（JSON形式）にすると、外部ストレージのフォルダ内へ、複数ファイルを一括コピーします。
フォルダ内に同名のファイルが存在する場合は、上書きコピーされます。

@method app.control(request)
リクエスト文字列をネイティブ側に送り、独自実装された処理を行います。
@param request {String} リクエスト文字列
@note
ネイティブ側では、以下の関数でリクエスト文字列を受け取ることができます。
  - win10：AppWebViewController.cpp ... void control(CStringW req)
  - macOS/iOS：AppWebViewController.m ... - (void)nativeControl:(NSString *)request
  - android：AppMainActivity.java ... public void control(final String request)

@method app.webauth(url, [scheme])
外部ブラウザを起動し、url で指定された OAuth 認証ページを表示します。
@param url {String} OAuth 認証用 URL
@param option scheme {String} 認証コード取得用のカスタム URL スキーム
@note
認証コードは、Universal Links/AppLinks や カスタム URL スキーム を利用して、app.event.command('url', url) で取得します。

@method app.barcode()
カメラを起動し、QR コードの読み取りを開始します。読み取ったデータは、app.event.command('barcode', text) で通知されます。
@atention iOS/Android のみ対応です。

@category $native.app.event

@method app.event.command(param1, param2)
ネイティブで発生したコマンドを通知します。
@param param1 {String} コマンドパラメータ1（実装依存）
@param param2 {String} コマンドパラメータ2（実装依存）
@note
以下のコマンドがシステムで使用されています。
  - app.event.command('exit') ... アプリケーションの終了通知（#define ENABLE_APP_EXIT が必要）
  - app.event.command('open', file) ...  オープンするファイルの通知
  - app.event.command('download', url) ... ダウンロードする url の通知
  - app.event.command('import', file) ... インポートしたファイルの通知（複数選択可の場合は、file はパスの配列）
  - app.event.command('export', url) ... エクスポート先の url の通知（キャンセルした場合は、url は ''（空文字））
  - app.event.command('url', url) ... Universal Links/AppLinks や カスタム URL スキーム による通知
  - app.event.command('barcode', text) ... QR コードの読み取り通知（キャンセルした場合は、text は ''（空文字））

uid に ''（空文字）を設定した場合は、標準のオーディオ出力が選択されます。

@method tgif.param(pid, [value])
pid で指定された音源パラメータ値を value に変更します。引数に value を指定しない場合は、現在の設定値を返します。
@param pid {Number} パラメータID

@param option msg2 {String} 17 ～ 32 ch 拡張分（HEX 形式）

@method tgif.thru(enable)
MIDI Thru 機能の有効／無効を切り替えます。有効にすると、接続しているMIDI入力からのMIDIメッセージを、直接音源に送信します。

@method tgif.buffer([num])

@category $native.seq

@method seq.load(data, [cue])
シーケンサーに SMF データをロードします。引数に cue を指定しない場合は、再生開始位置はトラック先頭になります。
@param data {String} SMF データ（HEX 表記）
@param option cue {Boolean} 最初にノート情報がある位置まで再生開始位置を頭出しする（true）／頭出ししない（false）
@return {Boolean} ロードに成功した場合は true を、失敗した場合は false を返します。
@atention SMF は Format 0/1 のみ対応です。

@method seq.play([loop])
シーケンサーのデータを、再生します。引数に loop を指定しない場合は、通常再生（トラック終端で停止）を行います。
@param option loop {Boolean} ループ再生（true）／通常再生（false）

@method seq.pause()
シーケンサーの再生を、一時停止します。

@method seq.stop()
シーケンサーの再生を、停止します。

@param option beatsA {Number} 開始位置（拍数）
@param option beatsB {Number} 終了位置（拍数）
@return {Array} 現在の範囲（[0]：開始位置、[1]：終了位置）

@method seq.tempo([bpm])
シーケンサーのテンポ（BPM）を設定、取得します。bpm の範囲は 10 ～ 480 です。引数に bpm を指定しない場合は、取得のみを行います。
@param option bpm {Number} 設定するテンポ（BPM）
@return {Number} 現在のテンポ（BPM）

@method seq.mute([channels])

@param option channels {Number} ミュートするチャンネル情報（ビット列、LSB:CH1）
@return {Number} ミュート中のチャンネル情報（ビット列、LSB:CH1）

@method seq.transpose([shift])

@param option shift {Number} 設定するシフト値
@return {Number} 現在のシフト値

@method seq.countin([bars])

@param option bars {Number} 設定する小節数
@return {Number} 現在の小節数

@method seq.metro([on])
メトロノームのオン／オフを設定、取得します。引数に on を指定しない場合は、取得のみを行います。
@param option on {Boolean} オン（true）／オフ（false）
@return {Boolean} 現在のオン／オフ

@method seq.metroset(notes)
メトロノームの拍ごとのノート情報を設定します。
@param notes {Array} ノート情報の配列
@note
例）metroset(['99227F', '99217F'])
配列の要素がメトロノームの拍数より少ない場合は、配列の最後の要素を利用します。
17 ～ 32 ch を指定する場合は、先頭に 'F5 + {後続のバイト数}' を追加してください。
例）metroset(['F503' + '90227F', 'F503' + '90217F'])

@method seq.countset(notes)
カウント・インの拍ごとのノート情報を設定します。
@param notes {Array} ノート情報の配列

@method seq.position()

@return {Number} 再生位置（拍数）

@method seq.totalbeats()
SMF データのトータルの拍数を返します。
@return {Number} トータルの拍数

@method seq.measure([beats])
指定された拍位置での小節情報を取得します。引数に beats を指定しない場合は、現在の再生位置で取得します。
@param option beats {Number} 位置（拍数）
@return {Array} 小節情報
@note
小節情報の配列要素
  - [0] {Number} 拍数
  - [1] {Number} 拍子記号（分子）
  - [2] {Number} 拍子記号（分母）
  - [3] {Number} メトロノーム1拍あたりの長さ（24 = 4分音符）
  - [4] {Number} 小節数
  - [5] {Number} 小節内での拍数（整数部）
  - [6] {Number} 小節内での拍数（小数部）
  - [7] {Number} カウント・イン中の残りのカウント数

  - copyright {String} 著作権表示

@method store.launchflow(params)
商品の購入処理を開始します。
@param params {Object} 購入要求オブジェクト
@note
購入要求オブジェクト
- type {String} 商品タイプ
- id {String} 商品識別子
- option quantity {Number} 購入数量（iOS 用 消費型のみ有効）
- option account {String} 難読化されたアカウント情報（UUIDv4 形式）
- option old {String} プラン変更元の商品識別子（Android 用）
- option proration {Number} プラン変更モード（Android 用）
（プラン変更モード）
- 1: すぐにプランが変更され、残りの期間は価格差に応じて調整され、次回更新時に充当されます（デフォルト）。
- 2: すぐにプランが変更され、残りの期間の差額が次回更新時に請求されます（アップグレードのみ利用可）。
- 3: すぐにプランが変更され、次回更新時に新しい価格が請求されます。
- 5: すぐにプランが変更され、新プランは全額が請求されます。古いプランの残額は引き継がれるか、別プラン変更時に期間内で比例配分されます。
- 6: 次回更新時に新しいプランに変更されます。
