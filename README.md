インストールする際は、サブモジュールである Quattro フレームワークもあわせてインストールする必要があります。以下のコマンドを実行して Clone してください
```
git clone --recurse-submodules https://rja.backlog.jp/git/QTTR2REPO/quattro-starter-kit.git
```

スターターキットに含まれている具体的な内容や使い方を知りたい場合は[ドキュメント](https://rja.backlog.jp/document/QTTR2REPO/0196fbdacbef7d0eac8e2377de45207c)を参照してください。
